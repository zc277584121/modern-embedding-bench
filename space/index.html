Reproduction

Python code is the only editable source of truth. Every result links to an immutable Git commit and the executable module that produced it. 

git checkout <source_commit>
uv sync
uv run python -m benchmarks.mock_showcase

Publication

This Space is read-only. New Tasks, Datasets, Solutions, and experiments are reviewed through GitHub pull requests and run in the maintained environment.

Result model

The underlying dimensions are Solution × Task × Dataset × Metric × Version. Dataset releases are immutable, and new test data is published as a new version.
