🏆 Modern IR Bench

Compare models, retrieval algorithms, RAG pipelines, and agent systems across modern information retrieval tasks.

Solution × Task

A compact view of each solution’s primary score and rank per task.

Each task keeps its own primary metric. Scores are not averaged into an overall score.

01

One result, one source

Every measurement points to an immutable Git commit and the exact executable Python module that produced it. There is no YAML registry. 

git checkout <source_commit>
uv sync
uv run python -m benchmarks.mock_showcase
02

Read-only publication

New Tasks, Datasets, Solutions, and experiments enter through reviewed GitHub pull requests. The official runner produces the displayed results.

03

Honest dimensions

Results use Solution × Task × Dataset × Metric × Version. Unrelated task metrics are not collapsed into a misleading overall score.
